## 📋 Overview

This repository contains comprehensive study notes for the **Android App Development (EI-333)** course. It is structured as a professional textbook, covering everything from the basics of mobile computing to advanced Android development concepts.

---

## ✨ Key Topics Covered

* **Mobile Computing & Platforms:** Characteristics, Android vs iOS.
* **Java for Android:** OOP recap, Collections, Multithreading.
* **Android Architecture:** Dalvik VM, ART, Linux Kernel.
* **The Four Pillars:** Activity, Service, Content Provider, Broadcast Receiver.
* **Activity Lifecycle:** Deep dive with real-world scenarios.
* **UI & Layouts:** XML, ConstraintLayout, Adapters, RecyclerView.
* **Data Storage:** SharedPreferences, SQLite, File storage.
* **Web Services:** JSON parsing, HttpURLConnection, OkHttp.
* **Multimedia & Telephony:** MediaPlayer, Camera API, Notifications.
* **Android NDK:** JNI, C/C++ integration.
